# Obsidian & PKM Glossary

Acronyms and terms you'll hit while learning Obsidian.

## Obsidian-specific
| Term | Means | What it is |
|------|-------|------------|
| Vault | — | The root folder of your notes. Just a folder of `.md` files. |
| MOC | Map of Content | A hand-curated index note that links out to related notes. |
| Backlink | — | A note that links *to* the current note ("what links here"). |
| Outlink | — | A link *from* the current note to another. |
| Transclusion / Embed | — | Pulling another note's content inline with `![[note]]`. |
| Callout | — | A highlighted box (`> [!note]`, `> [!warning]`) for emphasis. |
| Frontmatter / Properties | — | YAML metadata at the top of a note (between `---` lines). |
| Alias | — | An alternate name for a note so links resolve to it. |
| Canvas | — | Obsidian's infinite whiteboard for arranging notes visually. |
| Graph view | — | Visual map of notes connected by links. |
| Core plugin | — | Built-in feature you toggle on (Templates, Daily notes). |
| Community plugin | — | Third-party add-on installed from the browse list. |
| DQL | Dataview Query Language | Query syntax for the Dataview plugin. |

## Broader PKM (note-taking methodology)
| Term | Means | What it is |
|------|-------|------------|
| PKM | Personal Knowledge Management | The whole practice of capturing/organizing what you know. |
| ZK | Zettelkasten | "Slip-box" method: atomic notes heavily cross-linked. |
| PARA | Projects, Areas, Resources, Archives | Tiago Forte's folder framework for organizing by actionability. |
| LYT | Linking Your Thinking | Nick Milo's link-first methodology (where MOCs come from). |
| Atomic note | — | One idea per note. Keeps notes reusable and linkable. |
| Evergreen note | — | A note you continuously refine over time, not a one-off. |
| WYSIWYG | What You See Is What You Get | Live-preview editing (vs raw Markdown source mode). |
| MD | Markdown | The plain-text formatting these notes use. |
