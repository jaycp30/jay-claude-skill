# Welcome — Learning Vault

My personal knowledge base. Plain Markdown, synced via git/GitHub, editable by Claude Code.

## How this vault is wired
- **Sync:** git only (no iCloud/OneDrive on this folder — one sync system, no conflicts).
- **Agent:** `cd` here and run `claude` to let it read/write notes. House rules live in [[CLAUDE]].
- **Account:** personal → GitHub `jaycp30`.

## Daily habit
1. `Cmd+N` — new note for whatever you learned today.
2. Link it with `[[ ]]` to related notes.
3. Tag it: `#aws`, `#devops`, `#claude-code`.
4. Commit when you stop: `git add . && git commit -m "notes: <what>"`.

## Cheat sheet
| Action | Key |
|---|---|
| New note | `Cmd+N` |
| Jump to note | `Cmd+O` |
