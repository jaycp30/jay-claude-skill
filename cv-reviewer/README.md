# CV/Resume Reviewer Claude Skill

This skill creates a repeatable CV/resume workflow based on the video: Diagnose, Score, Rewrite, and Prep.

## What it does

- Reviews a CV like an ATS and recruiter.
- Scores it against a target job description.
- Finds missing keywords and weak sections.
- Rewrites bullets using achievement-led wording.
- Generates hiring-manager style interview prep.

## How to install in Claude

Zip the `cv-resume-reviewer-skill` folder and upload it as a custom skill in Claude.ai, or place the folder where your Claude Skills setup expects skills.

The required file is `SKILL.md`. Supporting references and templates are optional but included.

## Suggested first prompt

Use this skill to review my CV for this role. Diagnose it, score it, rewrite weak bullets, and prepare me for interview questions. Do not invent experience or metrics.
