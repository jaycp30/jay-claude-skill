# ATS Checklist

Use this checklist when reviewing a CV/resume.

## Formatting

- Use standard headings: Summary, Skills, Experience, Education, Certifications, Projects.
- Avoid important text inside images, text boxes, headers/footers, charts, or complex tables.
- Use simple bullet points.
- Keep dates in a consistent format.
- Use readable fonts and normal spacing.
- Avoid icons for key information such as phone, email, location, LinkedIn, GitHub.

## Content

- Include target role title or close equivalent near the top.
- Include relevant tools and technologies exactly as commonly written in job descriptions.
- Put strongest, most relevant experience in the first half of page one.
- Use achievement-led bullets instead of task lists.
- Include measurable outcomes where available.

## Keywords

Extract keywords from the job description across:

- Role title and function.
- Required technologies/tools.
- Cloud platforms and services.
- Programming/scripting languages.
- Frameworks and methodologies.
- Compliance/security terms.
- Domain-specific terms.
- Soft skills that are specifically emphasised.

## Red Flags

- Generic summary that could fit anyone.
- Claims without evidence.
- Keyword stuffing.
- Inconsistent job titles or dates.
- Overly long CV for the target market.
- Bullets that only describe duties.
- Missing core requirements from the target job.
