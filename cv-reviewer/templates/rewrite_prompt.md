# CV Rewrite Prompt

Use this prompt with the skill:

Please review and rewrite my CV for the following target role.

Target role:
[role title]

Target country/market:
[country]

Job description:
[paste job description]

Current CV:
[paste CV]

What I want:
- Diagnose the CV like an ATS and recruiter.
- Score it against the job description.
- Identify missing keywords and weak sections.
- Rewrite my headline, summary, skills, and experience bullets.
- Use achievement-led bullets following the idea: Accomplished X, as measured by Y, by doing Z.
- Do not invent metrics or experience. Use placeholders where I need to provide more detail.
- Prepare likely interview questions based on the rewritten CV and role.
